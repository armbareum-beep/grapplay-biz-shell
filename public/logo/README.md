# 파이네시스 로고 자산

| 파일 | 용도 |
|---|---|
| `pns-black.png` | 원본 — 검정 PNS 심볼 / 흰 배경 (1254×1254) |
| `pns-white.png` | 원본 — 흰 PNS 심볼 / 검정 배경 (1254×1254) |
| `pns-symbol.png` | 검정 심볼만 투명 배경으로 추출 (1048×573). 헤더 등 UI에 넣을 때 사용 |

파비콘(`/favicon-*.png`, `/favicon.ico`, `/apple-touch-icon.png`)은 `pns-symbol.png`를 정사각형 캔버스에
여백 10%로 맞춰 생성했다. 다크 모드용(`favicon-dark-*.png`)은 흰 심볼 / 검정 배경.

워드마크(글자 로고)는 한국어 **파이네시스** 로 쓴다 (계획: `docs/plan/10-rebrand-phynesis.md` D2).
